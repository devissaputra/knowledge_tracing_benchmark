# Research Bundle Visuals

Professor-facing diagrams in this directory describe the current multi-model research workflow. They are explanatory figures, not substitutes for measured results.

Authoritative empirical evidence is generated by `src/run_experiment.py` and stored in:

- `results/metrics.json` — machine-readable study record;
- `results/summary.md` — generated comparison table;
- `paper/results.md` — generated manuscript results;
- `results/figures/calibration.png` — measured held-out calibration figure.

Synthetic examples are restricted to software fixtures such as `scripts/run_demo.py` and are not research evidence.
