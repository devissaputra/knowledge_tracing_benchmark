# Research Bundle Visuals

The diagrams in this directory describe the current multi-model empirical workflow. They are explanatory figures, not substitutes for measured results.

Authoritative empirical evidence is generated by `src/run_experiment.py` and stored in:

- `results/metrics.json` — machine-readable study record;
- `results/summary.md` — generated comparison table and seed-stability summary;
- `paper/results.md` — generated manuscript results;
- `results/figures/calibration.png` — measured held-out calibration figure.

Synthetic data are restricted to automated test fixtures and are never used as empirical evidence.
